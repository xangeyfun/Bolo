# Bolo

A simple multipurpose Discord bot built with Python and `discord.py`.

## Setup
1. Clone the repository.

2. Install the Dependencies:
```bash
pip install -r requirements.txt
```

3. Create a `.env` file:
```
TOKEN=your_discord_bot_token
```

4. Start the bot:
```bash
python bot.py
```
